# LT Hisab Release Acceptance Checklist — v1.1.0

## Implemented in Source
- [x] Personal cash book only (Cash In / Cash Out with mandatory amount & notes).
- [x] Exact integer-paise arithmetic (`BigDecimal` parsing, Indian & International formatting).
- [x] All, Daily, Weekly, Monthly, Yearly, and Custom Date Range filters; launches on All Entries (configurable).
- [x] Runtime 3-language switcher (English, Hindi, Kherwara-local Vagdi in Devanagari) wired to UI and PDF.
- [x] Light theme (`#4B1028` burgundy) and Dark theme (OLED black + `#FFD600` yellow).
- [x] Original LT Hisab and SAROTECH logos preserved with valid extensions (`lt_hisab_logo.png`, `sarotech_logo.jpg`).
- [x] Persistent DataStore settings for all display, date/time, currency, profile, and opening-balance options.
- [x] Edit transaction, confirmed delete, search, sort, date/time pickers, and recent notes suggestions.
- [x] 4-digit PIN lock, Change PIN, security-question recovery, and Android BiometricPrompt.
- [x] Versioned JSON backup/restore (v2 + v1 support) with validation and restore confirmation.
- [x] Multipage Devanagari-safe PDF (`StaticLayout`) with logos, user info, opening/closing balances, repeated headers, page numbers, footer (`Generated by LT Hisab • SAROTECH`), PrintManager, and Email chooser.
- [x] Unit tests for calculator, backup validation, and localization.
- [x] GitHub Actions CI workflow (`.github/workflows/android.yml`).
