# LT Hisab — Android Source Project (v1.1.0)

**Personal Cash Book · SAROTECH**

## Features & Product Configuration
- **Minimum Android**: API 26 (Android 8.0+), Kotlin, Jetpack Compose, Room, DataStore.
- **100% Offline Personal Cash Book**: Cash In / Cash Out with mandatory amount (exact integer-paise via `BigDecimal`) and notes, edit/confirmed-delete, custom date & time, recent notes suggestions, search, sort, and custom date range.
- **Periods & Running Balance**: All Entries (default on launch), Daily, Weekly (configurable Mon/Sun), Monthly, Yearly, and Custom Date Range with opening/carried-forward balance support.
- **Instant 3-Language Support**: English, Hindi (हिंदी), and Kherwara-local Vagdi in Devanagari (वागड़ी) across every screen, dialog, and generated PDF.
- **Themes**:
  - Light: soft light surfaces with deep burgundy accent (`#4B1028`).
  - Dark: OLED black (`#000000`) with yellow accent (`#FFD600`).
- **Original Branding**: Retains original LT Hisab (`lt_hisab_logo.png`) and SAROTECH (`sarotech_logo.jpg`) artwork in original colors.
- **Multipage PDF, Print & Email**:
  - Uses Android `StaticLayout` for full Devanagari/English text wrapping.
  - Embeds both original logos, optional user name & address, selected period, opening/closing balance, repeated table headers, page numbers, and `Generated by LT Hisab • SAROTECH` footer.
  - Android Print Framework (`PrintManager`) and system Email chooser integration.
- **Security**: Optional 4-digit PIN lock (salted SHA-256), security-question PIN recovery, and Android `BiometricPrompt`.
- **Backup & Restore**: Versioned local JSON (v2 with v1 compatibility), strict validation, SAF save/share, and restore confirmation dialog.

## Build with GitHub Actions
1. Push the contents of the `LT-Hisab` directory to your GitHub repository (ensure `.github/workflows/android.yml` is at the repo root).
2. GitHub Actions automatically runs `gradle testDebugUnitTest` and `gradle assembleDebug` on JDK 17 + Gradle 8.9.
3. Download the APK from the workflow's **Artifacts** (`lt-hisab-debug-apk`).
